스타벅스 팀 통합 프로젝트

1. VS Code에서 이 폴더 전체를 엽니다.
2. index.html을 우클릭하여 Open with Live Server로 실행합니다.
3. 상단 COFFEE, MENU, WHAT'S NEW 및 고객지원 메뉴로 이동할 수 있습니다.
4. 공통 헤더: shared-header.css / 공통 푸터: shared-footer.css
5. 각 페이지의 원래 CSS/JS 파일은 유지했습니다.
6. STORE, REWARDS 등 담당 페이지가 없는 메뉴는 연결되지 않았습니다.
7. 외부 스타벅스 이미지와 CDN은 인터넷 연결이 필요합니다.
8. 공통 헤더/푸터 HTML은 각 페이지에 직접 삽입되어 있습니다. 수정 시 각 HTML을 함께 수정해야 합니다.
